# virt 板上的 RV32

[English](../en/rv32.md)

这是第 5 步的第一台机器。`src/linux-0.11/` 仍然是 80386 内核。`src/rv32/` 是旁边的另一份内核。它打开页表，打印机器信息，然后留下一个 shell。盘上的程序是 `ls`、`echo` 和 `sleep`。同一批问题在[课程](course.md)里，这一台机器的停法在[RV32 这一遍](course/rv32.md)。

Bochs 和 gem5 的 x86 运行都不变。这份内核单独启动：

```bash
labs/rv32/qemu/launch.sh
```

脚本编译出 `src/rv32/kernel.elf` 以及 `sh`、`ls`、`echo`、`sleep`，写好 `images/rv32.img`，并用 `qemu-system-riscv32 -machine virt -cpu rv32 -bios none` 启动。控制台是这块板子的 UART。`help` 列出盘上的程序。`exit` 关机。按 F5 并选择 **RV32**，会停在 `entry.S` 的 `_start`，也就是内核的第一条指令。UART 输出在那个任务的终端里。同一菜单里的 **Linux 0.11** 仍是 80386 的会话，`labs/i386/qemu/launch.sh` 仍然为它打开 VGA 窗口。两个会话都听 `127.0.0.1:1234`，一次启动一个。

## 这次运行打印什么

启动时先打印机器信息，然后是 shell 提示符。`$ ` 和命令列表来自 `src/user/sh.c`。机器信息来自 `main.c`，`disk` 是启动时找到的 virtio 设备：

```text
rv32
hart 0
uart 0x10000000
timebase 10000000
sv32 on
disk 0x10008000
$ ls
ls
sh
echo
sleep
$ echo hello
hello
$ sleep 10
$ exit
```

`uart`、`timebase` 和 `disk` 是这次启动从设备树读到的值。上面的数字来自 QEMU 10.2.1。以后的 QEMU 可以把 UART 放在别处；内核跟着它拿到的那棵树走。

`images/rv32.img` 里是 `ls`、`sh`、`echo` 和 `sleep`。它们是链接在 `0x10000` 的 RV32 ELF。内核把 `sh` 载入用户态，shell 留在那里。`fork` 拷走一页栈，`exec` 换进敲下的程序，`exit` 再换回来。80386 的磁盘仍是 `rootfs/hdc-0.11.img`。内核从 UART 读一行，并把这一行回显出来。

`swtch` 保存的寄存器和 [xv6-riscv](https://github.com/mit-pdos/xv6-riscv) 一样：`ra`、`sp`，以及 `s0` 到 `s11`。xv6 是 64 位内核，UART 地址是写死的。这份内核是 RV32，UART 从设备树读取。

## 这块板子

`virt` 是 QEMU 的 RISC-V 机器，不是可以买到的芯片。位宽由模拟器二进制和 `-cpu rv32` 决定。这颗 CPU 是 RV32GC。这份内核是整数代码，所以用 `-march=rv32gc -mabi=ilp32` 编译。

板子的说明在 [QEMU 的 virt 页面](https://www.qemu.org/docs/master/system/riscv/virt.html)。CPU 列表在 [RISC-V 目标页面](https://www.qemu.org/docs/master/system/target-riscv.html)。

这块板的内存从 `0x80000000` 开始，内核就链在这里。QEMU 的复位向量跳到 `_start`，当时是 M-mode，`a0` 是 hart 号，`a1` 是设备树。`fdt.c` 顺着这棵树走。UART 是 `compatible` 为 `ns16550a` 的那个节点。这块板上 `soc` 总线的 `ranges` 是空的，所以 `reg` 里的地址就是物理地址。时钟频率是 `timebase-frequency` 属性。关机是向 `sifive,test` 那个节点写一个字。

## 五件事

| 事情 | 位置 | 和 80386 内核相比 |
| --- | --- | --- |
| 启动 | `entry.S`、`main.c` | `_start` 在 M-mode 运行，然后 `mret` 进入 S-mode。没有固件，也没有引导扇区。 |
| 页表 | `vm.c` | Sv32，两级，4KiB 页。`satp` 指向根表。没有 GDT。 |
| 时钟 | `traps.c` | 进提示符之前写 `stimecmp`，之后每拍再装一次。中断是监管者原因 5。没有 8259。 |
| 任务切换 | `swtch.S` | `exec` 保存 shell 并进入子进程，`exit` 再换回来。没有 TSS。 |
| 复制一页 | `mem.c` | `fork` 里的 `copy_page` 拷 1024 个字，共 4KiB，和 80386 上一样大。 |

名字本身看不出作用的指令在[一页](rv32_instructions.md)里。80386 的名字，以及只属于那台 CPU 或那台 PC 的行，在 [80386 那一页](i386_instructions.md)。

Sv32、`mret`、PMP 和 `stimecmp` 在 [RISC-V 特权规范](https://github.com/riscv/riscv-isa-manual)。
