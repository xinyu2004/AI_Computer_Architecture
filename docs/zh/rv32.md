# virt 板上的 RV32

[English](../en/rv32.md)

这是第 5 步的第一台机器。`src/linux-0.11/` 仍然是 80386 内核。`src/rv32/` 是旁边的另一份内核，做同样的五件事：启动、页表、一次时钟中断、一次任务切换、复制一页 4KiB。它没有文件系统，没有 tty，也没有磁盘。

按 F5 启动的仍是 **Linux 0.11**。Bochs 和 gem5 的 x86 运行都不变。这份内核单独启动：

```bash
labs/rv32/launch.sh
```

脚本编译出 `src/rv32/kernel.elf`，并用 `qemu-system-riscv32 -machine virt -cpu rv32` 启动。控制台是这块板子的 UART。`labs/qemu/launch.sh` 仍然为 80386 内核打开 VGA 窗口。

## 这次运行打印什么

OpenSBI 先打印它自己的横幅。横幅里有两行是交接：`Domain0 Next Address : 0x80400000` 和 `Domain0 Next Mode : S-mode`。然后内核打印：

```text
rv32
hart 0
uart 0x10000000
timebase 10000000
sv32 on
timer
task 1
copy_page 4096
task 0
```

`uart` 和 `timebase` 是这次启动从设备树读到的值。上面的数字来自 QEMU 10.2.1 和 OpenSBI 1.8。以后的 QEMU 可以把 UART 放在别处；内核跟着它拿到的那棵树走。

`swtch` 保存的寄存器和 [xv6-riscv](https://github.com/mit-pdos/xv6-riscv) 一样：`ra`、`sp`，以及 `s0` 到 `s11`。xv6 是 64 位内核，UART 地址是写死的。这份内核是 RV32，UART 从设备树读取。

## 这块板子

`virt` 是 QEMU 的 RISC-V 机器，不是可以买到的芯片。位宽由模拟器二进制和 `-cpu rv32` 决定。这颗 CPU 是 RV32GC。这份内核是整数代码，所以用 `-march=rv32gc -mabi=ilp32` 编译。

板子的说明在 [QEMU 的 virt 页面](https://www.qemu.org/docs/master/system/riscv/virt.html)。CPU 列表在 [RISC-V 目标页面](https://www.qemu.org/docs/master/system/target-riscv.html)。

QEMU 把 OpenSBI 放在 `0x80000000`，把这份内核放在 `0x80400000`。这个地址是 32 位 virt 机器上 `-kernel` 的固件交接地址。设备地址不从这里取。OpenSBI 把设备树放在 `a1`，`fdt.c` 顺着它走。UART 是 `compatible` 为 `ns16550a` 的那个节点。这块板上 `soc` 总线的 `ranges` 是空的，所以 `reg` 里的地址就是物理地址。时钟频率是 `timebase-frequency` 属性。

## 五件事

| 事情 | 位置 | 和 80386 内核相比 |
| --- | --- | --- |
| 启动 | `entry.S`、`main.c` | OpenSBI 已经在 M-mode。内核从 S-mode 开始。没有 BIOS，也没有引导扇区。 |
| 页表 | `vm.c` | Sv32，两级，4KiB 页。`satp` 指向根表。没有 GDT。 |
| 时钟 | `traps.c`、`sbi.c` | `ecall` 请 OpenSBI 设置下一次到期时间。中断是监管者原因 5。没有 8259。 |
| 任务切换 | `swtch.S` | 软件保存 `ra`、`sp` 和 `s0`–`s11`，再装入另一个任务。没有 TSS。 |
| 复制一页 | `main.c` | 循环写 1024 个字，共 4KiB，和 80386 上的 `copy_page` 一样大。 |

名字本身看不出作用的指令在[一页](rv32_instructions.md)里。80386 的名字，以及只属于那台 CPU 或那台 PC 的行，在 [80386 那一页](i386_instructions.md)。

时钟调用和关机调用是 SBI 的 TIME 和 SRST 扩展。调用的文字在 [SBI 规范](https://github.com/riscv-non-isa/riscv-sbi-doc)。Sv32 在 [RISC-V 特权规范](https://github.com/riscv/riscv-isa-manual)。
