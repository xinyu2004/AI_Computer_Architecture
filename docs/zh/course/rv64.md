# RV64 上的位宽

[English](../../en/course/rv64.md)

[问题表](../course.md)

RV64 回答的是和 [RV32](rv32.md) 同一批问题。盘上的程序仍是 `sh`、`ls`、`echo` 和 `sleep`。课程页上的表是 80386、RV32、ARMv7、AArch64。RV64 不单开一列。

```sh
labs/rv64/qemu/launch.sh
```

脚本用 `-march=rv64gc -mabi=lp64` 编译 `src/rv64`，再用 `qemu-system-riscv64 -machine virt -cpu rv64 -bios none` 启动。UART 先打印 `rv64`，再打印 `sv39 on`，然后是 `$`。按 F5 并选择 **RV64**，停在 `_start`。Linux 0.11、RV32、RV64、ARMv7 和 AArch64 都听 `127.0.0.1:1234`，一次启动一个。

有三处停法随位宽变。

在 `vm.c` 的 `vm_on` 里，断在写 `satp` 的那条指令。模式域是第 63 到 60 位，值是 8。这是 Sv39，页表有三级。单步越过这次写入。UART 打印 `sv39 on`。

`$` 已经出现、还没有按键时，断在 `traps.c` 的 `trap_handler`。`scause` 是 `0x8000000000000005`。中断位在第 63 位，低位仍是 5。外部中断是 `0x8000000000000009`。U-mode 的 `ecall` 仍是 8。`stimecmp` 是一个寄存器 `0x14d`。

断在 `swtch.S` 的 `swtch`，输入 `echo hello`。每个保存的寄存器占 8 字节。断在 `mem.c` 的 `copy_page`，输入 `ls`。一页 4KiB 是 512 次 8 字节的存储。

指令名仍是 [RV32 那一页](../rv32_instructions.md)。搬动的位在[那一页末尾](../rv32_instructions.md#rv64-上搬动的位)。
