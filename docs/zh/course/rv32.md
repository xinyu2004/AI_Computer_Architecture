# RV32 上的前八问

[English](../../en/course/rv32.md)

[问题表](../course.md)

启动仍是 `labs/rv32/qemu/launch.sh`。UART 在这个终端里。F5 选 **RV32**，停在 `entry.S` 的 `_start`，再下断点。断在函数上。地址以这次编译为准。

## UART 上先看这段

```text
rv32
hart 0
uart 0x10000000
timebase 10000000
sv32 on
disk 0x10008000
$ ls
ls
sh
echo
sleep
$ echo hello
hello
$ nosuch
not found
$ sleep
sleep: ms
$ sleep 10
$ exit
```

`sleep 10` 停 10ms，终端里像没停。要看见停顿，用 `sleep 1000`。`uart`、`timebase` 和 `disk` 来自这一次的设备树，QEMU 10.2.1 打出过上面的数。

`fork` 在 `exec.c` 里调用 `copy_page`。`exec` 装入程序后调用 `swtch`，子进程从自己的 `_start` 跑。`exit` 再 `swtch` 回 shell。回来用的是 `fork` 时留下的页面，内核不会把 `sh` 从磁盘再读一遍。`current_name` 在子进程运行时是那个程序的名字，回到提示符后是 `sh`。

## 停在哪

### 上电 {#boot}

F5 停在 `_start`。`a0` 是 hart，`a1` 是设备树。继续运行后，UART 打出机器信息，然后是 `$`。

### mret {#mode}

断在 `entry.S` 的 `mret`。单步过去以后是 S-mode。

### satp {#pages}

断在 `vm.c` 的 `vm_on`，看写 `satp` 的那条。单步过去，UART 接着打出 `sv32 on`，然后才是提示符。

### U-mode {#privilege}

`$` 出现以后，断在 `exec.c` 的 `syscall`。敲回车。进来时上一个模式是 U-mode。调用号在 `a7`。

### scause {#timer}

`$` 已经出现，还没敲字。断在 `traps.c` 的 `trap_handler`。`scause` 是 `0x80000005`：最高位是 1，低位是 5。`current_name` 是 `sh`。继续两次，会再进来两次。每次 `stimecmp` 都更晚一拍。这一拍是 `timebase / 100`，这块板上是 10ms。

### ecall {#ecall}

断在 `syscall`。敲 `echo hello`。shell 的 `exec` 进来时 `a7` 是 3。`echo` 写 UART 时 `a7` 是 1。UART 打出 `hello`。

### swtch {#switch}

断在 `swtch.S` 的 `swtch`。再敲 `echo hello`。第一次留下的是 shell，装入的是 `echo` 的 `_start`。`echo` 退出时再进一次，回到 shell 下一次读行。

### copy_page {#copy}

断在 `mem.c` 的 `copy_page`。再敲一次 `ls`。函数走一遍，源是 shell 的栈页，目标是子进程的栈页，1024 个字，4096 字节。回到 `$` 之后下一行还能读。

敲 `nosuch`。UART 打出 `not found`。`swtch` 和 `copy_page` 都不进。

断在 `trap_handler`，敲 `sleep 10`。等待时 `current_name` 是 `sleep`，`scause` 仍是监管者时钟。等待结束再经 `swtch` 回到 shell，然后 UART 才打出 `$`。
